# About

Welcome to **kroikie.dev**!

I'm Arthur Thompson ([@kroikie](https://github.com/kroikie)), an engineer exploring the intersection of modern software engineering and autonomous AI agents.

## The Mission

Software development is undergoing a fundamental shift. We are moving from writing code line-by-line to orchestrating teams of specialized agents, designing deterministic boundaries, and rethinking developer workflows from first principles.

This blog serves as a living notebook and field journal for:
- **Agentic Architectures**: Multi-agent delegation patterns, tool design, and state management.
- **Practical Field Notes**: Hands-on lessons, patterns, and trade-offs discovered while building real-world systems with agents.
- **Modern App Craft**: How architecture, testing, code quality, and engineering rigor evolve when AI agents become core collaborators.
